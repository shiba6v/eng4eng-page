コーディング面接で解き方を英語で説明する練習

コードは書けても、解き方を英語で説明しようとすると言葉が止まる。そんなときは、よく使う短い文を口に出す練習から始めましょう。

最初の方針を伝える

たとえば『まず単純な方法を試します』なら、I’ll start with a simple approach. と言えます。『この方法では配列を一度走査します』は、This approach scans the array once. のように、動作を短く説明します。

日本語を見てから英語で答える

エンジニア英語面接では、日本語の問題文を見て英文を考えます。解答を開き、模範解答や別の表現と比較しましょう。音声を聞いて言い直す練習もできます。

言いにくかった表現を復習する

解答の下で、どのくらい言えたかを4段階で選びます。難しかった表現を繰り返し練習し、説明の出だしが自然に言える状態を目指します。
